## The Problem FMCG Brands Have

FMCG brands in Africa operate with **6–8 week lag time** on sales data. Their distribution chain:

```
Factory → National Distributor → Regional Wholesaler → Local Kiosk → Consumer
```

By the time data flows back up this chain, it is:
- **Aggregated** (no granular SKU-level insights)
- **Delayed** (trend has shifted by the time they see it)
- **Incomplete** (informal retailers don't report accurately)

ACE operates **at the last mile** — where the actual sale happens. We see it in real-time.
