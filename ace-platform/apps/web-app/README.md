# Web App

> **ACE Platform — Phase 2**  
> The primary merchant-facing commerce OS.

## Responsibility

The full-featured browser application that merchants use to manage their entire business. This is the respond.io-equivalent product — a unified inbox and commerce command centre.

## Key Modules

- **Unified Inbox** — All conversations across all channels in one view
- **Orders** — Pipeline, fulfilment status, history
- **Inventory** — Real-time stock, variants, supplier management
- **Customers** — CRM, profiles, purchase history, balance tracking
- **Analytics** — Revenue dashboards, demand forecasts, customer cohorts
- **Campaigns** — Re-engagement flows, promotions, automated sequences
- **Team** — User management, roles, activity log
- **Settings** — Channel connections, integrations, AI configuration

## Design Principles

- Mobile-first responsive (merchants use phones)
- Offline-capable for core views
- Low data mode for 3G markets
- English + Pidgin UI copy option
